# datalaw_recnik — Rečnik, сербско-русский словарь для Android (онлайн + офлайн по кнопке)

Capacitor 8 · Preact · TypeScript · Vite. Версия **0.0.1** (дальше +1 в последнем знаке: `npm run bump`).
Брат-близнец приложения Lexa (англо-русский): то же оформление DataLaw DesignLab, та же схема данных и сборки.

> Готового открытого сербско-русского словаря нет, поэтому данные **выводятся** из Викисловаря — см. «Откуда переводы» ниже. Качество переводов зависит от этого и честно помечается в интерфейсе.

## Как работают данные
Словарь собирается в CI и публикуется в ветку `dictionary` репозитория; приложение читает файлы оттуда «на лету» (с кэшем). В **Настройки → Данные** — кнопка «Скачать для работы офлайн»: весь словарь сохраняется на устройстве. Без скачивания приложение работает онлайн.

**Хостинг — бесплатно и без настроек.** Job `data` публикует собранный словарь в ветку `dictionary` этого репозитория, а приложение читает `https://raw.githubusercontent.com/<owner>/<repo>/dictionary/`. Нужно только, чтобы репозиторий был **публичным**. GitHub Pages не нужен. Адрес можно переопределить через `VITE_DATA_URL` (и поправить `DEFAULT_DATA_URL` в `src/config.ts`, если владелец репозитория не `diman-dragon`).

В dev-режиме (`npm run data:sample && npm run dev`) данные берутся из `public/data` локально.

## Откуда переводы

| Что | Источник | Лицензия |
| --- | --- | --- |
| Сербскохорватские статьи (`sh`), IPA, формы слов, русские переводы | Викисловарь через [kaikki.org](https://kaikki.org) (Wiktextract) | CC BY-SA |
| Частотность, ранжирование подсказок | [wordfreq](https://pypi.org/project/wordfreq/) | CC BY-SA |
| Предложения SR↔RU | [Tatoeba](https://tatoeba.org) | CC BY 2.0 FR |
| Озвучка | системный синтезатор речи Android | — |

Прямых пар «сербское слово — русское слово» в Викисловаре почти нет. Поэтому `scripts/build_data.py` строит их через английский:

1. **Точные пары** — в английской статье в одном значении (одной «глоссе») есть и сербский (`sh`), и русский перевод. Они попадают в словарь как есть.
2. **Приблизительные** (метка «≈ приблизительно») — у сербской статьи простое английское значение («dog»), и русские переводы берутся у английской статьи с той же частью речи. Могут быть неточны.
3. Формы слов (`psa → pas`) ведут на основное слово; обратный индекс **RU→SR** строится из тех же пар; примеры — предложения Tatoeba по ключу слова.

Сербский вводится латиницей, кириллицей и **без диакритики** («kuca» → «kuća»); в настройках выбирается, каким письмом показывать слова. Кириллический ввод определяется как сербский и/или русский по буквам (ђ ј љ њ ћ џ — сербские; ё ы э ъ ь щ ю я й — русские), общие слова показываются из обоих словарей с пометкой SR/RU.

```bash
npm run data:sample   # крошечный образец (12 слов) — мгновенно, для разработки
npm run data:build    # полная сборка: pip install wordfreq; качает несколько ГБ, 30–90 мин
```

Размер и состав: `--max-words 120000`. Адреса дампов — константы в начале скрипта (`KAIKKI_URLS`, `TATOEBA_*`), можно передать свои: `--kaikki-url`, `--kaikki файл.jsonl.gz`.

## Подпись: обновление поверх установленного

Android ставит APK «поверх» только если **подпись та же** и `versionCode` больше:

- ключ `signing/datalaw_recnik.keystore` **лежит в репозитории** (публичный; алиас и пароль `datalaw_recnik`) — CI и локальные сборки подписаны одним ключом;
- в CI `versionCode` = номер запуска workflow; локально задайте `VERSION_CODE=<больше установленного>`;
- SHA-256 сертификата: `01:EF:AD:B4:10:F4:C3:87:DD:72:32:3A:90:2F:AD:E4:C1:68:36:9B:68:45:9B:29:74:E5:CE:45:2E:F1:0E:86`.

⚠️ Ключ публичный — любой может подписать APK тем же ключом. Для личной установки и открытого проекта это нормально, для Google Play — нет. Не пересоздавайте ключ: иначе обновление поверх станет невозможным.

## Быстрый старт

Node 22+, Python 3.10+ (+ `pip install pillow numpy` для иконок), JDK 21, Android SDK.

```bash
npm install
npm run data:sample      # или data:build
npm run check            # типы + TS-тесты + тесты пайплайна данных
npm run dev              # http://localhost:5173
npm run android:release  # → release/datalaw_recnik-0.0.1.apk (подписанный)
npm run android:open     # открыть в Android Studio
```

## GitHub Actions

`.github/workflows/android.yml`: `check` (типы, тесты; единственное, что идёт на pull request) → `data` (сборка словаря, кэш по хэшу скрипта; публикация в ветку `dictionary`) → `android` (подписанный APK, артефакт `datalaw_recnik-apk`; по тегу `v*` — ещё и GitHub Release). Для публикации включите *Settings → Actions → Workflow permissions → Read and write*.

## Интерфейс

- 4 вкладки внизу со свайпами: Поиск · Мои слова · История · Настройки
- Поиск SR и RU с подсказками, слово дня; карточка слова: значения (русские переводы по частям речи), формы, примеры SR↔RU, IPA, род/вид, частотность
- Настройки — подэкраны со свайпами: Вид (тема Авто / Светло-коричневая / AMOLED), Язык (интерфейс RU/EN, сербское письмо, проверка голосов), Данные, Источники, О нас
- Системная кнопка «Назад» идёт по шагам и в конце закрывает приложение
- Строки интерфейса — `src/i18n.ts`

## Оформление, иконка, озвучка
- Оформление общее с другими приложениями DataLaw DesignLab (`datalaw_forma`): токены цветов в начале `src/styles/app.css`.
- Иконка: `python3 scripts/make-icons.py` строит знак из `resources/logo-source.png` («D» DataLaw DesignLab) + книга (медный оттенок, чтобы отличать от Lexa); `scripts/android_icons.py` подставляет её в проект Android (в CI делает `release-apk.sh`).
- Озвучка — системный синтезатор Android. Нативный плагин `scripts/android/RecnikSpeechPlugin.java`; `scripts/android-patch.mjs` кладёт его в `android/` и добавляет в манифест `<queries>` для TTS. Сербский: `sr-RS`, при отсутствии голоса — `hr-HR`/`bs-BA` (звучат почти так же).

## Ограничения

- Переводы выводятся через английский: покрытие неполное, «приблизительные» могут быть неточны. Это не замена бумажному словарю.
- Пайплайн данных проверен на образце формата kaikki; реальные дампы из этой среды скачать не удалось — при первой полной сборке проверьте адреса, имена полей (`lang_code`, `sh`) и логи.
- Предложения Tatoeba привязываются к однословным ключам; фразы примеров не получают.
- Озвучке нужны установленные в системе голоса.
